# Чтец для Android

Читает вслух русские тексты из **.doc, .docx, .md, .bin, .txt, .rtf** с актёрской интонацией —
та же логика, что в версии для компьютера (вопросы, восклицания, многоточия, диалоги, паузы).

## Чтецы

В настройках чтения — список чтецов. Чтец — это голос рассказчика: голос Microsoft, голос телефона, темп
и высота. Заведите нескольких («＋ Добавить чтеца»), послушайте каждого кнопкой ▶ и выберите, кто читает
(нажмите на строку). ✎ — настроить: имя, оба голоса, темп, высота, проба «▶ Microsoft» и «▶ Телефон».
Голос любого чтеца можно одним выбором отдать персонажу в окне «Роли».

Длинные названия голосов в списках переносятся на несколько строк.

## Роли: каждому персонажу — свой голос

Кнопка с двумя человечками вверху экрана чтения.

* Персонажи находятся по тексту автоматически, без интернета:
  * по словам автора: «— Привет, — **сказал Иван**», «**ответила Марья Сергеевна**», «**всплеснула руками** Анна»,
    «Иван повернулся и сказал:» перед репликой; пол — по глаголу («сказал» / «сказала»);
  * «он» / «она» — последний упомянутый персонаж этого пола; «сказал я» — герой-рассказчик;
  * обращение по имени («— **Иван**, дело есть») и «спросил он **меня**» — кто ответит следующим;
  * реплики без подписи в диалоге двоих — по очереди.
* Каждому персонажу выдаётся голос **на всю книгу** и запоминается для этой книги: мужчинам — Дмитрий,
  женщинам — Светлана, и у каждого свой сдвиг высоты и темпа, чтобы персонажи не сливались. Для голосов
  телефона персонажи получают разные русские голоса. Герой-рассказчик говорит голосом рассказчика.
* В окне «Роли» — список персонажей (пол, число реплик, голос). Нажмите на персонажа: пол, голос Microsoft,
  голос телефона, высота, темп, «читать голосом рассказчика», «▶ Проба». «Раздать голоса заново» —
  заново найти персонажей и раздать голоса. Роли можно выключить галочкой.
* Во время чтения внизу видно, кто говорит: «Иван Петрович: …».

## Библиотека (стартовый экран)

* **«Новое»** — ищет по всему телефону (внутренняя память и карта памяти) файлы, которые можно прочитать:
  .doc, .docx, .md, .txt, .rtf и .bin (из .bin — только те, где действительно есть русский текст).
  Новые файлы помечаются «НОВОЕ» и собираются на вкладке «Новые». При первом поиске Android попросит
  «Доступ ко всем файлам» — приложение только читает файлы и ничего не отправляет.
* **＋** — добавить файлы вручную (можно несколько сразу), **⋮ → «Вставить свой текст»**.
* **Полки:** «Читаю» (книга попадает сюда сама, когда вы начинаете слушать), «Прочитано» (сама — когда
  дослушали до конца), «Неинтересные» (такие файлы не показываются во «Все»).
* **Свои сборки:** «＋ Сборка» — например «Детективы», «На дачу». Подержите сборку, чтобы переименовать
  или удалить её.
* **⋮ у книги** (или подержать книгу) — разложить по полкам и сборкам, убрать из списка (сам файл не удаляется).
* У каждой книги виден процент прослушанного, вверху — карточка «Продолжить» с последней книгой.
* Поиск по названию — строка вверху.

Если приложение когда-нибудь закроется с ошибкой, при следующем запуске оно покажет текст ошибки —
его можно скопировать или отправить разработчику.

## Как это устроено

**Аудиодорожка.** Текст заранее, на несколько фраз вперёд, озвучивается в звуковые файлы, и они играют
подряд без пауз между ними. Поэтому:
* пауза и продолжение — ровно с того же слова;
* чтение идёт в фоне при выключенном экране;
* управлять можно из уведомления, с экрана блокировки и кнопками наушников (⏮ ⏯ ⏭);
* при звонке ставится на паузу и продолжается после, при отключении наушников — пауза.

**Подсветка со слежением.** Текущая фраза подсвечена мягким жёлтым, звучащее слово — ярким и бежит по
тексту, только что прочитанное становится серым. Текст плавно прокручивается за чтением (если вы сами
листаете — прокрутка ждёт 4 секунды). Для голоса Microsoft время слов точное (его присылает сервис),
для голоса телефона — рассчитанное по длине слов и знакам препинания.

**Закладки.**
* «Где вы остановились» запоминается само для каждого документа — и при паузе, и при закрытии
  приложения. Откроете тот же файл снова (даже из другой папки) — курсор будет на этом месте, ▶ продолжит.
* Свои закладки: кнопка 🔖 внизу — отмечает текущее слово, можно записать заметку. Список — кнопкой
  с закладкой вверху: перейти, перейти и читать, изменить заметку, удалить. Места закладок подсвечены
  в тексте сиреневым.

## Голоса и работа без интернета

| | Голос Microsoft | Голос телефона |
|---|---|---|
| Качество | лучше, «живой» | хорошее |
| Интернет | нужен при первой озвучке | не нужен |
| Голоса | Дмитрий, Светлана | русские голоса, установленные в телефоне |
| Сохранение в файл | MP3 | WAV |

* **Авто** (по умолчанию): есть интернет — Microsoft, нет — голос телефона. Если сеть пропала посреди
  чтения, дальше читает голосом телефона без остановки.
* Озвучка голосом Microsoft **сохраняется в телефоне** (до 1 ГБ, старое удаляется само) — перечитывание
  работает без интернета.
* **⋮ → «Подготовить книгу для офлайна»** — озвучить всю книгу голосом Microsoft заранее (например, дома
  по Wi-Fi) и потом слушать её в дороге без интернета.

## Телефоны Samsung (One UI 7 и новее, в т.ч. Galaxy S25/S26)

Samsung закрыл свой синтезатор «Модуль TTS Samsung» для сторонних приложений начиная с One UI 7
(Android 15): Android сам подменяет его на Google. Обойти это приложению нельзя. «Чтец» это распознаёт,
сам подключает «Синтезатор речи Google» и пишет об этом в настройках чтения.

Настройка один раз:
1. Настройки телефона → Общие настройки → Преобразование текста в речь (или поиск в настройках:
   «Преобразование текста в речь») → Предпочитаемый модуль → **Распознавание и синтез речи от Google**.
   Если его нет — установите «Распознавание и синтез речи от Google» (Speech Recognition and Synthesis
   from Google) из Play Маркета.
2. Там же — шестерёнка у модуля Google → Установка голосовых данных → Русский → скачать (для работы без интернета).
3. В «Чтеце»: настройки (ползунки) → «Только голос телефона» или «Авто» → синтезатор «Синтезатор речи Google» →
   выберите голос, слушая кнопкой «▶ Проба» (голоса с пометкой «офлайн» работают без интернета).
4. «Проверить голоса и связь» — самопроверка на телефоне с отчётом, который можно отправить.

Ещё бесплатные офлайн-голоса — синтезатор **RHVoice** (кнопка в настройках чтения).

## Установка готового APK

1. Скопируйте `chtec.apk` на телефон (через кабель, Telegram, Google Диск — как удобно).
2. Откройте файл на телефоне. Android попросит разрешить установку из этого источника — разрешите.
3. Если Play Защита предупредит о неизвестном разработчике — «Подробнее» → «Всё равно установить».
   (Приложение подписано личным ключом, а не ключом магазина, поэтому так.)

Нужен Android 7.0 или новее.

**Голоса телефона.** В настройках чтения — один список всех голосов всех установленных синтезаторов
(Google, VoxSherpa, RHVoice и др.), сначала русские, с пометкой синтезатора и «офлайн / нужен интернет».
Только что установленный синтезатор появляется сразу. Рассказчик и персонажи могут быть из разных
синтезаторов. Кнопка «▶ Проба» даёт послушать голос. Под списком — состояние каждого синтезатора
(сколько у него русских голосов). Синтезаторы на нейросетях вроде VoxSherpa читают по-русски, только
если в них скачана русская модель (например, Piper ru_RU).

Для **голоса телефона** нужен русский голос: Настройки → Специальные возможности →
Синтез речи (или кнопка «Скачать голоса телефона…» в приложении) → «Синтезатор речи Google» →
скачать русский язык. На большинстве телефонов он уже есть.

## Как пользоваться

* Книгу открывают из библиотеки, а также из любого файлового менеджера или мессенджера:
  «Открыть с помощью» / «Поделиться» → Чтец. Можно поделиться и просто текстом. **←** — назад в библиотеку
  (чтение при этом продолжается в фоне).
* **▶** — читает с места курсора (коснитесь текста, чтобы поставить его); выделите фрагмент, чтобы
  прочитать только его. **⏮ ⏭** — на фразу назад/вперёд, **■** — стоп.
* **✎** — режим правки: можно менять текст и вставлять свой. Вне правки текст только читается.
* **Настройки** (значок с ползунками) — режим голоса, голоса рассказчика и персонажей, темп, высота,
  актёрская интонация, размер текста, прокрутка за чтением, сохранённая озвучка.
* **⋮** — читать с начала, сохранить озвучку в файл, подготовить книгу для офлайна.

## Сборка из исходников

**Android Studio:** File → Open → папка `android` → дождаться синхронизации → Run ▶
(или Build → Build App Bundle(s) / APK(s) → Build APK(s)). Сторонних библиотек нет.

**Без Android Studio** (Linux, Debian/Ubuntu):
```bash
sudo apt install aapt apksigner zipalign dalvik-exchange openjdk-17-jdk
ANDROID_JAR=/путь/к/android-34/android.jar ./build_apk.sh   # результат: build/chtec.apk
```

  ReaderService.java     аудиодорожка в фоне, оба голоса, кэш для офлайна, уведомление и экран блокировки

  core/TextExtractor.java  .doc/.docx/.md/.bin/.txt/.rtf, определение кодировки

### Если голоса Microsoft перестали работать

Это неофициальный доступ (тот же, что у функции «Читать вслух» в браузере Edge), и Microsoft
время от времени меняет защиту. Тогда приложение читает голосом телефона. Чтобы починить, нужно обновить
`EdgeDrm.java` и версию в `EdgeTts.java` по свежей версии библиотеки
[edge-tts](https://github.com/rany2/edge-tts) (`edge_tts/drm.py`, `edge_tts/constants.py`).
