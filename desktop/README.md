# Чтец — озвучка русских текстов с актёрской интонацией

Читает вслух файлы **.doc, .docx, .md, .bin** (а также .txt и .rtf) нейросетевым голосом
(Дмитрий или Светлана, голоса Microsoft через `edge-tts`) и сохраняет озвучку в MP3.

## Как получается «актёрское» чтение

* **Знаки препинания** управляют интонацией каждого предложения:
  * `?` — вопросительная мелодия, голос чуть выше;
  * `!` — живее, громче и выше;
  * `?!` — удивлённый вопрос;
  * `…` и `...` — медленнее и тише, длинная пауза («недосказанность»);
  * запятые, тире, двоеточия — паузы внутри фразы делает сам нейросетевой голос.
* **Паузы** разной длины после точки, вопроса, многоточия, в конце абзаца и после заголовка.
* **Диалоги** (`— Привет, — сказал он. — Как дела?`) разбираются на реплики и слова автора:
  реплики читаются живее или другим голосом (например, рассказчик — Дмитрий, персонажи — Светлана).
* **Заголовки** читаются медленнее, с паузой после.
* Сокращения (`т. е.`, `т. д.`, `г.`, инициалы) не обрывают предложение; ссылки, разметка Markdown
  и блоки кода не читаются; числа и даты голос произносит сам с правильными окончаниями.

## Форматы

| Формат | Как читается |
|---|---|
| `.docx` | абзацы, заголовки по стилям, таблицы |
| `.doc` | старый Word 97–2003, свой разбор (не нужен ни Word, ни LibreOffice) |
| `.md` | без разметки: заголовки, списки, таблицы, ссылки → только текст |
| `.bin` | определяется по содержимому: Word внутри, текст в UTF-8 / UTF-16 / CP1251 / KOI8-R, а из настоящих бинарных файлов извлекаются русские фрагменты текста |

## Установка

Нужен Python 3.9+ и интернет (синтез голоса идёт через сервис Microsoft).

```bash
pip install -r requirements.txt
```

Для кнопки «Стоп» желательно установить [ffmpeg](https://ffmpeg.org/) (используется `ffplay`);
без него MP3 откроется в стандартном проигрывателе системы.

## Запуск

**Окно программы** (Windows — двойной щелчок по `chtec.bat`):

```bash
python chtec.py
```

Откройте файл, выберите голоса, темп и высоту, нажмите «Слушать» или «Сохранить MP3…».
Если выделить часть текста, прочитан будет только выделенный фрагмент. Текст можно и просто вставить.

**Командная строка:**

```bash
python chtec.py книга.doc                       # сохранит книга.mp3 рядом (запускать из папки desktop)
python chtec.py заметки.md --play               # озвучить и сразу прослушать
python chtec.py роман.docx --voice dmitry --dialog-voice svetlana --rate -5
python chtec.py файл.bin --score                # показать разметку интонаций без озвучки
python chtec.py текст.txt --flat                # ровное чтение без актёрской интонации
```

Пример разметки (`--score`):

```
[narrator  heading          пауза  900 мс] Глава 1. Встреча.
[narrator  ellipsis         пауза  800 мс] Был тихий вечер…
[character exclaim          пауза  375 мс] Привет!
[narrator  statement        пауза  325 мс] крикнул кто-то из-за забора.
[character question         пауза  900 мс] Ты куда так спешишь?
```

Тонкая настройка интонаций и пауз — таблицы `PROSODY` и `PAUSE_AFTER` в `reader/prepare.py`.

## Устройство

```
chtec.py            окно (tkinter) и командная строка
reader/extract.py   чтение .doc/.docx/.md/.bin/.txt, определение кодировки
reader/prepare.py   нормализация, предложения, интонации, диалоги, паузы
reader/speak.py     синтез голоса и склейка в один MP3
reader/player.py    воспроизведение
../examples/        примеры файлов всех форматов (в корне репозитория)
```
