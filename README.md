# Чтец

Читает вслух русские книги и документы с актёрской интонацией: вопросы, восклицания, многоточия, паузы,
диалоги — и разные голоса для разных персонажей.

Форматы: **.doc, .docx, .md, .txt, .rtf, .bin** (из .bin — текст в любой русской кодировке, Word внутри
или русские фрагменты из бинарных файлов).

## Android — `android/`

Готовый APK: [`releases/chtec-1.6.apk`](releases/chtec-1.6.apk) (Android 7+).

* библиотека: поиск книг на телефоне, полки «Читаю / Прочитано / Неинтересные», свои сборки;
* чтение в фоне как аудиодорожка: пауза с точного места, экран блокировки, кнопки наушников;
* подсветка читаемой фразы и бегущего слова, плавная прокрутка за чтением;
* закладки с заметками и место остановки для каждой книги;
* голоса Microsoft (Дмитрий, Светлана; повторное прослушивание — без интернета) и все голоса телефона
  (Google, VoxSherpa, RHVoice…); режим «Авто» сам переходит на голос телефона без сети;
* **роли**: персонажи находятся по тексту, каждому — свой голос на всю книгу;
* несколько **чтецов** с пробой голоса у каждого;
* самопроверка голосов и связи с отчётом.

Подробно: [`android/README.md`](android/README.md). Сборка — Android Studio (открыть папку `android`)
или `android/build_apk.sh` без Android Studio.

## Компьютер — `desktop/`

Python-версия с окном и командной строкой, сохраняет озвучку в MP3: [`desktop/README.md`](desktop/README.md).

```bash
cd desktop && pip install -r requirements.txt
python chtec.py ../examples/пример.md --play
```

## Проверки — `tests/`

```bash
./tests/run.sh
```

Сверяют Java-ядро Android-приложения с Python-версией (разбор файлов и интонации), привязку слов к тексту,
определение ролей на размеченных рассказах, токен доступа к голосам Microsoft и клиент Microsoft на
имитации сервера.

## Устройство

```
android/app/src/main/java/ru/chtec/core/   общее ядро на чистой Java (проверяется на компьютере)
  TextExtractor, Cfb      чтение файлов и кодировок
  Prepare                 интонации, паузы, диалоги
  Roles                   кто говорит
  Aligner, Timing         подсветка: где фраза и слово в тексте и когда они звучат
  EdgeTts, EdgeDrm        голоса Microsoft (WebSocket-клиент и токен)
android/app/src/main/java/ru/chtec/        экраны, фоновое чтение, библиотека, голоса телефона
desktop/                                   Python-версия
examples/                                  примеры файлов всех форматов
tests/                                     проверки
```
